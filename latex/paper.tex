       Type-in-Type}
\author{Pavel Sokolov}

\maketitle

\begin{abstract}
We present a dependently typed pure type system which
contains a circular axiom $s:s$ for a certain sort $s$
and is nonetheless strongly normalizing. Girard's
paradox is avoided because our sorts are not closed
under a $\Pi$-former: function types are placed in sorts
according to their \textit{rank}. We prove strong
normalization of a system and provide a barebones
set-theoretical model for it. A normalization proof
is surprisingly simple (modulo general metatheoretical
properties of pure type systems) and has been fully
formalized in vanilla Rocq (formerly Coq) without any
additional axioms.
\end{abstract}

\section{Introduction}
Pure type systems (PTSs) are a family of minimalistic
typed $\lambda$-calculi including grammar formers for
variables $x\in\mathsf{Var}$, abstraction
$\lambda(x:T).t$, application $t\,t'$, types of
dependent functions $\Pi(x:T).U$ (where $U$ might depend
on $x$) and \textit{sorts} $s\in\mathcal{S}$ which act
like ``types of types''. In contrast with many other
type systems, there is no syntactical distinction
between terms and types --- they are defined by a single
grammar; an expression can act both as a term and as a
type depending on a side where it stands next to the
colon in the typing judgement $\Gamma\vdash\_:\_$.
A single PTS is determined by two relations:
\begin{itemize}
\item \textit{axiom} relation $\mathsf{Ax}\subseteq
    \mathcal{S}\times\mathcal{S}$ determines ``to which
    sort(s) a given sort belongs as an element'';
    instead of $(s,s')\in\mathsf{Ax}$ it is customary to
    write simply $s:s'$.
\item \textit{rule} relation $\mathsf{Rule}\subseteq
    \mathcal{S}^2\times\mathcal{S}$ places types of
    functions $\Pi(x:T).U$ into sorts accounting for the
    sorts where $T$ and $U$ are situated.
\end{itemize}

\and
\inferrule[Rule]{

}{\Gamma\vdash\Pi(x:T).\,U:s}

Systems from Barendregt's lambda cube fit naturally into
the framework: for example, simply typed lambda calculus
(STLC) can be viewed as a pure type system with a single
sort $*$, no axioms and a single rule $(*,*,*)$. In
general, however, a pure type system is dependently
typed since $\Pi$ allows the codomain type to depend on
the value of an argument --- Coquand's Calculus of
Constructions (CoC) sits comfortably at the top of
lambda cube and is modeled as a pure type system with
two sorts $\{*,\square\}$, a single axiom $*:\square$
and four rules corresponding to simple functions
$(*,*,*)$, polymorphic functions $(\square,*,*)$, type
operators $(\square,\square,\square)$ and dependent
types $(*,\square,\square)$.

As is known, both STLC and CoC are strongly normalizing
and sound with respect to their set-theoretical
semantics. A classical result shows that it is not true
for arbitrary PTS.

\begin{theorem*}[Girard'72]
    The following PTS called System U is not
    normalizing:
    \[\begin{array}{c}
        \mathcal{S}=\{*,\square,\triangle\},
        \quad\mathsf{Ax}=\{
            (*,\square),(\square,\triangle)
        \},
        \\ \mathsf{Rule}=\{
            (*,*,*),(\square,*,*),(\triangle,*,*),
            (\square,\square,\square),
            (\triangle,\square,\square)
        \}
    \end{array}\]
    Futhermore, the offending term has type
    $\Pi(P:*).P$.
\end{theorem*}

This result is dubbed ``Girard's paradox'' since it
renders System U inconsistent with respect to its
intended logical semantics: inhabitedness of
$\Pi(P:*).P$ would mean that every proposition is
provable. Thus any system where System U embeds is
inconsistent, too; in particular, an original version of
Martin-L\"{o}f's Intuitionistic Type Theory embeds the
following PTS known as ``Type-in-Type'' which is
inconsistent due to Girard's paradox:
\[\mathcal{S}=\{*\},\quad\mathsf{Ax}=\{*:*\},\quad
\mathsf{Rule}=\{(*,*,*)\}.\]
For a pure type system with usual set-theoretical
semantics, it is natural to expect that a sort of
\textit{small types} $*$ is closed under $\Pi$, thus we
cannot forbid the rule $(*,*,*)$; then, a circular axiom
$*:*$ has to go. Long story short, it motivates an
introduction of a \textit{universe hierarchy}
$\mathcal{S}=\{\mathcal{U}_k\}_{k\in\mathbb{N}}$ with
axioms $\mathcal{U}_k:\mathcal{U}_{k+1}$ and rules
$(\mathcal{U}_k,\mathcal{U}_l,\mathcal{U}_{k\vee l})$
for each $k,l$; when interpreted in sets,
$\llbracket \mathcal{U}_k \rrbracket$ is taken to be the
$k$-th inaccessible cardinal.

Observing this, we took interest in the following two
questions:

\begin{itemize}
\item If we were to drop the rule $(*,*,*)$ and keep the
    axiom $*:*$ instead, can we find a nontrivial
    consistent pure type system?
\item Is there a consistent pure type system with total
    relations $\mathsf{Ax}$ and $\mathsf{Rule}$ whose
    natural set-theoretical semantics do not involve
    assumption of inaccessible cardinals?
\end{itemize}

Turns out that, for both questions, answer is ``yes''.
Furthermore, both yes-s are witnessed by a single PTS,
which we dub PTS-$rk$:
\[
\mathcal{S}=\{\mathsf{rk}_r\}_{r\in\mathbb{N}}
\quad
\mathsf{Ax}=
    \{(\mathsf{rk}_r,\mathsf{rk}_0)\}_{r\in\mathbb{N}}
\quad
\mathsf{Rule}=
    \{(\mathsf{rk}_r,\mathsf{rk}_s,
        \mathsf{rk}_{(r+1)\vee s})\}_{r,s\in\mathbb{N}}
\]
(Naming ``$\mathsf{rk}$'' comes from \textit{rank},
since rules compute precisely the rank of functions,
which is the maximal nesting of $\Pi$ in the domain
type.)

Indeed, there is a circular axiom
$\mathsf{rk}_0:\mathsf{rk}_0$, and System U is not
embeddable since $\mathsf{rk}_r$ is not closed
under $\Pi$ for any $r$. Also, as we will see in
Section~\ref{rk-soundness}, our PTS-$rk$ is strongly
normalizing and has a set-theoretical model in ZFC
despite an intuition that $\mathsf{rk}_r:\mathsf{rk}_0$
might ``feel wrong''. Modulo general metatheory of pure
type systems laid out in Section~\ref{pts-metatheory},
a normalization proof turned out to be suspiciously
simple, even more so in comparison with normalization
proofs of other dependently typed systems. To dispel our
own doubts, we formalized a proof of normalization in
Rocq (formerly Coq) without using any additional axioms,
yielding a fully constructive proof; our journey in
formalization is summarised in
Section~\ref{formalization}. We provide a closing
summary and some pointers on possible extensions of the
system in Section~\ref{conclusion}.

\section{Metatheory of pure type systems}
\label{pts-metatheory}

For ease of presentation of our results, in
Sections~\ref{pts-metatheory}-\ref{rk-soundness} we take
a Barendregt convention which assumes that all bound
variables are distinct from free variables and from each
other; furthermore, $\alpha$-equivalence (renaming of
bound variables) is assumed as a trivial equality on
terms. Nevertheless, our formalization takes variable
treatment seriously; see Section~\ref{formalization} for
more details.

\subsection{PTS as a rewriting system}

In Fig.~\ref{typing}, a rule of \textit{conversion}
(\textsc{Conv}) mentions \textit{definitional equality}
of types $T=_\beta U$. It is defined as a reflexive,
symmetric, transitive closure of a one-step reduction.

\begin{definition}[One-step reduction]
Relation of a one-step reduction $t\to_\beta t'$ is the
smallest relation satisfying the following rules:
\begin{mathpar}
\inferrule{T \to_\beta T'}
    {\Pi(x:T).U \to_\beta \Pi(x:T').U}
\and
\inferrule{U \to_\beta U'}
    {\Pi(x:T).U \to_\beta \Pi(x:T).U'}
\and
\inferrule{T \to_\beta T'}
    {\lambda(x:T).t \to_\beta \lambda(x:T').t}
\and
\inferrule{t \to_\beta t'}
    {\lambda(x:T).t \to_\beta \lambda(x:T).t'}
\and
\inferrule{t \to_\beta t'}{t\,u \to_\beta t'\,u}
\and
\inferrule{u \to_\beta u'}{t\,u \to_\beta t\,u'}
\and
\inferrule[Beta]{}
    {(\lambda(x:T).t)\,u \to_\beta t[u/x]}
\end{mathpar}
\end{definition}

In essence, actual reduction happens only in rule
\textsc{Beta}; other rules simply state the we can
freely reduce any subterm.

The following result will be greatly useful in our
development. It was proven many times over for different
similar systems; we briefly revisit the proof since
previous presentations usually did not allow reductions
in the type of argument $T$ in $\lambda(x:T).t$.

\begin{theorem}[Characterization of $(=_\beta)$]
    In arbitrary PTS,
    \[
        t =_\beta u \quad\Leftrightarrow\quad
        \exists v.\;t\to_\beta^* v
        \land u\to_\beta^* v,
    \]
    where $(\to_\beta^*)$ is reflexive transitive
    closure of $(\to_\beta)$.
\end{theorem}
\begin{proof}
    Note that it is enough to prove that $(\to_\beta^*)$
    has a diamond property --- for each $t_0,t_1,t_2$
    such that $t_0\to_\beta^* t_1$ and
    $t_0\to_\beta^* t_2$ there exists a $t'$ such that
    $t_1\to_\beta^* t'$ and $t_2\to_\beta^* t'$:
    \[\begin{tikzcd}
        t_0 \arrow[r] \arrow[d]
        & t_1 \arrow[d, dashed] \\
        t_2 \arrow[r, dashed] & t'
    \end{tikzcd}\]
    Then, any ``mountains'' in the path $t=_\beta u$ can
    be switched into ``valleys''.

    Now, diamond property is proven by standard
    technique of parallel reduction which is defined as
    the smallest relation satisfying:
    \begin{mathpar}
    \inferrule{}{t\rightrightarrows t}
    \and
    \inferrule
        {T\rightrightarrows T' \\ U\rightrightarrows U'}
        {\Pi(x:T).U\rightrightarrows\Pi(x:T').U'}
    \and
    \inferrule
        {T\rightrightarrows T' \\ t\rightrightarrows t'}
        {\lambda(x:T).t\rightrightarrows
            \lambda(x:T').t'}
    \and
    \inferrule
        {t\rightrightarrows t'\\ u\rightrightarrows u'}
        {t\,u\rightrightarrows t'\,u'}
    \and
    \inferrule
        {t\rightrightarrows t'\\ u\rightrightarrows u'}
        {(\lambda(x:T).t)\,u\rightrightarrows t'[u'/x]}
    \end{mathpar}
    Intuitively, while $(\to_\beta)$ is a single
    $\beta$-reduction somewhere in the term and
    $(\to_\beta)^*$ is a sequence of reductions,
    $(\rightrightarrows)$ is several simultaneous
    reductions immediately available in the term.
    Notice, then, that $(\to_\beta)\subseteq
    (\rightrightarrows)\subseteq(\to_\beta^*)$; by
    monotonicity of reflexive transitive closure,
    $(\to_\beta^*)\subseteq
    (\rightrightarrows^*)\subseteq(\to_\beta^*)^*
    =(\to_\beta^*)$, so
    $(\rightrightarrows^*)=(\to_\beta^*)$. Thus it is
    enough to prove diamond property of
    $(\rightrightarrows^*)$. Diamond property is
    preserved under reflexive transitive closure, so it
    is enough to prove diamond propery of
    $(\rightrightarrows)$, which holds by tedious case
    analysis.
\end{proof}

Setting aside practical applications of this theorem (to
algorithmically check equivalence of terms, we can now
search for common reduction result), it will prove
useful already in our proof development. For example,
the following ``equality inversion'' lemmas are direct
corollaries:

\begin{corollary}[Equality inversion]
    If $s=_\beta s'$, then $s=s'\in\mathcal{S}$; if
    $\Pi(x:T).U=_\beta\Pi(x:T').U'$, then $T=_\beta T'$
    and $U=_\beta U'$.
\end{corollary}

They will become necessary in proving subject reduction,
or type preservation. But first, we will show some
structural properties of a typing judgement given in
Fig.~\ref{typing}.

\subsection{Properties of a typing judgement}

Again, they surely have been proven
before for PTS, but we slightly differ in the
formulation of typing rules in important places so it's
better to recheck that these hold.

\begin{lemma}[Weakening]
    The following rule is admissible:
    \[\dfrac{\Gamma,\Delta\vdash t:T}
            {\Gamma,x:U,\Delta\vdash t:T}.\]
\end{lemma}
\begin{proof}
    By structural induction on the typing derivation.
\end{proof}

\begin{lemma}[Substitution]
    The following rule is admissible:
    \[\dfrac{
        \Gamma,x:U,\Delta\vdash t:T\quad
        \Gamma\vdash u:U
    }{\Gamma,\Delta[u/x]\vdash t[u/x]:T[u/x]}.\]
\end{lemma}
\begin{proof}
    By structural induction on the typing derivation
    for $t$. For variables in $\Delta$, it is necessary
    that both $\Delta$ and $T$ get substitutions of $u$
    for $x$ so \textsc{Var} is still applicable; for
    places in $t$ where $x$ used to be we need to apply
    weakening lemma to the typing derivation for $u$
    exactly $|\Delta|$ times. In the case of
    \textsc{Conv} it is important that definitional
    equality of types is preserved by substitution
    (thanks to characterization of $(=_\beta)$).
\end{proof}

In addition, a family of so-called \textit{inversion
lemmas} stating that type of well-typed term is largely
determined by shape of a term are also proven by
straightforward induction on typing derivation (each one
is proven separately, no mutual induction involved):

\begin{lemma}[Inversion lemmas]
\begin{align}
    \Gamma\vdash s:T &\Rightarrow
    \exists s'. (s,s')\in\mathsf{Ax} \land T =_\beta s'
    \\
    \Gamma\vdash\Pi(x:T).U:V &\Rightarrow
    \exists s_T,s_U,s.\left\{\begin{array}{l}
        (s_T,s_U,s)\in\mathsf{Rule} \\
        \Gamma\vdash T:s_T \\
        \Gamma,x:T\vdash U:s_U \\
        V =_\beta s
    \end{array}\right. \\
    \Gamma,x:T,\Delta\vdash x:U &\Rightarrow T=_\beta U
    \\
    \Gamma\vdash\lambda(x:T).t:V &\Rightarrow
    \exists s,U.\left\{\begin{array}{l}
        \Gamma\vdash T:s \\
        \Gamma,x:T\vdash t:U \\
        V =_\beta \Pi(x:T).U
    \end{array}\right. \\
    \Gamma\vdash t\,u:V &\Rightarrow
    \exists U,T.\left\{\begin{array}{l}
        \Gamma\vdash t:\Pi(x:U).T \\
        \Gamma\vdash u:U \\
        V =_\beta T[u/x]
    \end{array}\right.
\end{align}
\end{lemma}

To progress further, we need to make certain assumptions
on the PTS we have in question.

\begin{definition}[Functional PTS]
    A pure type system is called \emph{functional} if
    $\mathsf{Ax}\subseteq\mathcal{S}\times\mathcal{S}$
    and $\mathsf{Rule}\subseteq\mathcal{S}^2\times
    \mathcal{S}$ are functional relations, that is,
    \[
        (s:s')\land(s:s'')\Rightarrow s'=s''
        \quad\text{and}\quad
        (s_1,s_2,s)\in\mathsf{Rule}\land(s_1,s_2,s')\in
        \mathsf{Rule}\Rightarrow s=s'
    \]
\end{definition}

\begin{definition}[Total PTS]
    A pure type system is called \emph{total} if
    $\mathsf{Ax}\subseteq\mathcal{S}\times\mathcal{S}$
    and $\mathsf{Rule}\subseteq\mathcal{S}^2\times
    \mathcal{S}$ are total relations, that is,
    \[
        \forall s.\exists s'.(s,s')\in\mathsf{Ax}
        \quad\text{and}\quad
        \forall s_1,s_2.\exists s.(s_1,s_2,s)\in
        \mathsf{Rule}
    \]
\end{definition}

\begin{theorem}[Uniqueness of typing]
    In a functional PTS, the following rule is
    admissible:
    \[\dfrac{\Gamma\vdash t:T \quad \Gamma\vdash t:T'}
        {T =_\beta T'}.\]
\end{theorem}
\begin{proof}
    By structural induction on $t$ and
    inversion of given typing derivations.
    \begin{itemize}
    \item $t=s\in\mathcal{S}$: by functionality of
        $\mathsf{Ax}$.
    \item $t=\Pi(x:T).U$: inversion of typing gives a
        pair of (possibly different) sorts for $T$ and
        another pair for $U$. By induction we get that
        ranks inside pairs are definitionally equal,
        which by equality inversion gives strictly equal
        sorts. Then what is needed holds by
        functionality of $\mathsf{Rule}$.
    \item Case for $t=x\in\mathsf{Var}$ holds trivially.
    \item $t=(\lambda(x:T).u)$: by induction hypotheses
        and by congruence of $(=_\beta)$.
    \item $t=u\,v$: by typing inversion and by induction
        hypothesis for $u$ we get $u:\Pi(x:T_1).U_1$ and
        $\Pi(x:T_1).U_1=_\beta\Pi(x:T_2).U_2$.
        We need $U_1[v/x]=_\beta U_2[v/x]$ which we
        get from equality inversion and preservation of
        def.eq. under substitution.
    \end{itemize}
\end{proof}

In our proof of normalization, we're going to rely on
yet another property: if there is a derivation for
$t:T$, then $T$ is itself typeable with some sort.
However, it doesn't hold in our current formulation of
typing rules: in $\Gamma\vdash x:T$, nothing prevents a
context $\Gamma$ to contain an entry $(x:T')$ where $T'$
is not typeable. Thus we need an additional assumption.

\begin{definition}[Context well-formedness]
    Context $\Gamma$ is \emph{well-formed} (written
    $\vdash\Gamma$) if every type in it is typed by some
    sort. Formally, set of well-formed contexts is the
    least set closed by the following rules:
    \[
        \dfrac{ }{\vdash\cdot} \quad\text{and}\quad
        \dfrac{\vdash\Gamma\quad\Gamma\vdash T:s}
              {\vdash\Gamma,x:T}
    \]
    (where $\cdot$ denotes an empty context.)
\end{definition}

Usually, when presenting a dependently typed system,
context well-formedness is added as a premise to typing
rules which would otherwise be premise-free (such as
\textsc{Ax} and \textsc{Var} in a PTS). Here we instead
provide it as an additional assumption only when
necessary; in addition to leading to simpler metatheory
(we avoid an otherwise mutually inductive definition of
$(\vdash\_)$ and $(\_\vdash\_:\_)$), this is closer to
how decision procedures for typing judgements are
implemented.

\begin{theorem}[Typing yields correct type]
\label{type-is-correct}
    In a total PTS, if $\Gamma\vdash t:T$ and
    $\vdash\Gamma$, then there exists $s\in\mathcal{S}$
    such that $\Gamma\vdash T:s$.
\end{theorem}
\begin{proof}
    By structural induction on typing derivation.
    \begin{itemize}
    \item \textsc{Ax}, \textsc{Rule}: by totality of
        $\mathsf{Ax}$.
    \item \textsc{Var}: follows from $\vdash\Gamma$.
    \item \textsc{Abs}: by totality of $\mathsf{Rule}$.
    \item \textsc{App}: $\Gamma\vdash t\,u:T[u/x]$.
        From induction hypothesis for $t$ we know that
        $\Gamma\vdash t:\Pi(x:U).T:s$ for some $s$,
        then by typing inversion for $\Pi(x:U).T$ we get
        that $T$ is typable with some sort. Then what is
        needed follows from substitution lemma.
    \item \textsc{Conv}: what is needed is present in
        the premise.
    \end{itemize}
\end{proof}

Totality is not a strictly necessary requirement ---
similar true propositions can be stated for non-total
PTS, for example in CoC typing yields type which is
either itself typable or equal to $\square$. But
PTS-$rk$ is indeed total so the theorem above is enough
for our purposes.

\begin{theorem}[Subject reduction]
    In a total PTS, the following rule is admissible:
    \[\dfrac{
        \Gamma\vdash t:T \quad \vdash\Gamma
        \quad t \to_\beta t'
    }{\Gamma\vdash t':T}\]
\end{theorem}
\begin{proof}
    By structural induction over derivation of
    $t\to_\beta t'$. Inversion of a typing judgement
    yields all necessary info, albeit because of it
    types are now given only up to definitional equality
    so we have to apply conversion rule in each case.
    Crucially, it requires the type we convert into to
    be typable by a sort, so that's where we use
    Theorem~\ref{type-is-correct}.

    The only tricky case are reductions of a domain type
    in $\Pi(x:T).U$ and $\lambda(x:T).t$. Let us
    consider the case of the following reduction:
    \[\lambda(x:T).t \to_\beta \lambda(x:T').t.\]
    In order to complete this case, we have to prove
    that $\Gamma,x:T'\vdash t:U$ given that
    $\Gamma,x:T\vdash t:U$. By appropriately
    strengthening the statement, we get that it is
    enough to prove admissibility of the following rule
    called \emph{context reduction}:
    \[\dfrac{
        \Gamma,x:U,\Delta\vdash t:T\quad
        \vdash\Gamma,x:U,\Delta\quad U\to_\beta U'
    }{\Gamma,x:U',\Delta\vdash t:T}\]
    The proof is, again, by induction on the typing
    derivation. The only non-trivial case is with
    \textsc{Var} rule used on $x$; it is taken care of
    by appropriate use of \textsc{Conv} rule to convert
    $x:U'$ to $x:U$. To use conversion, we have to prove
    that $U$ is well-typed; thankfully, it follows from
    $\vdash\Gamma,x:U,\Delta$.

    Note that context reduction is admissible in
    arbitrary PTS! We don't need it anywhere else,
    though, so we didn't state it as a separate lemma.
\end{proof}

Characterization of definitional equality, uniqueness of
typing and subject reduction together imply the
following corollary we're going to use a few times in
our normalization proof:

\begin{corollary}[Type stability]
    In a total functional PTS, the following holds:
    \[\left\{\begin{array}{l}
        \Gamma\vdash t:T\\
        \Gamma\vdash t':T'\\
        \vdash\Gamma\\
        t =_\beta t'
    \end{array}\right.\quad\Rightarrow\quad
    T=_\beta T'.\]
\end{corollary}

\subsection{Properties of strongly normalizing terms}

We're almost done with classical results! What is left
now is to state which terms are strongly normalizing and
collect properties of s.n. terms which allow our
soundness proof to go through.

Informally, a term is strongly normalizing iff there are
no infinite reduction chains starting from it.
In constructive setting and in formalization, the
following definition is a bit better:

\begin{definition}[Strongly normalizing term]
    Set of s.n. terms is the smallest set $\mathsf{sn}$
    in which the following rule is valid:
    \[\dfrac{\forall t',(t\to_\beta t')\Rightarrow
        t'\in\mathsf{sn}}{t\in\mathsf{sn}}.\]
    In other words, a term is strongly normalizing iff
    all possible reductions from it are strongly
    normalizing.
\end{definition}

The following properties are then provable by definition
of $\mathsf{sn}$ and by structural induction on
available derivations of $\mathsf{sn}$ for terms in
question:

\begin{lemma}[Structural properties of $\mathsf{sn}$]
\label{sn-props}
\begin{mathpar}
    \inferrule{}{x,s\in\mathsf{sn}}\and
    \inferrule{T\in\mathsf{sn}\\ U\in\mathsf{sn}}
        {\Pi(x:T).U\in\mathsf{sn}}\and
    \inferrule{T\in\mathsf{sn}\\ t\in\mathsf{sn}}
        {\lambda(x:T).t\in\mathsf{sn}}\and
    \inferrule{t\,u\in\mathsf{sn}}{t\in\mathsf{sn}}\and
    \inferrule{t[u/x]\in\mathsf{sn}}{t\in\mathsf{sn}}
\end{mathpar}
\end{lemma}

Application, of course, is the only nontrivial case. In
case of $\beta$-reduction, strong normalization of both
$(\lambda(x:T).t)$ and $u$ doesn't imply anything about
normalization behaviour of $t[u/x]$: consider a
classical example from untyped lambda calculus,
$\omega=(\lambda(x:T).x\,x)$ and
$\Omega=\omega\,\omega$; while obviously not typable,
$\omega$ is strongly normalizing, while $\Omega$
decidedly is not.

Situation changes when a head of application is not an
abstraction at all. Thus we arrive at the definition of
an \textit{atomic term}.

\begin{definition}[Atomic term]
    Set of atomic terms is the smallest set satisfying
    the following conditions:
    \begin{enumerate}
        \item $s$, $\Pi(x:S).T$ and $y$ are atomic for
            all variables $x$,$y$, sort $s$ and types
            $S$,$T$;
        \item If $t$ is atomic, then $t\,u$ is also
            atomic.
    \end{enumerate}
\end{definition}

Atomic terms are useful precisely because their strong
normalization survives application:

\begin{lemma}
    If $t,u\in\mathsf{sn}$ and $t$ is atomic, then
    $t\,u\in\mathsf{sn}$.
\end{lemma}
\begin{proof}
    By induction on derivations of $\mathsf{sn}$ for $t$
    and $u$. Consider possible redexes in $t\,u$: $t\,u$
    is not itself a redex since $t$ is atomic and hence
    not a lambda; the only possible redexes are either
    inside $t$ or inside $u$. Applying corresponding
    induction hypotheses, we reach the desired result.
    The only caveat is that, for induction to go
    through, we need to check that atomicity of $t$
    is preserved by reduction; this is indeed true by
    induction on derivation of atomicity for $t$.
\end{proof}

A dual view on strong normalization of application is
the following: if we already know that
$t[u/x]\in\mathsf{sn}$, then the most tricky case is
already taken care of.

\begin{lemma}
    \[\left\{\begin{array}{l}
        t[u/x]u_1\ldots u_n\in\mathsf{sn} \\
        U,u\in\mathsf{sn}
    \end{array}\right.\Rightarrow
    (\lambda(x:U).t)u u_1\ldots u_n\in\mathsf{sn}.\]
\end{lemma}
\begin{proof}
    By induction on $n$.
    \begin{itemize}
        \item $n=0$. We need to prove that if
            $t[u/x],u,U\in\mathsf{sn}$, then
            $(\lambda(x:U).t)u\in\mathsf{sn}$.
            Note that $t[u/x]\in\mathsf{sn}$ implies
            $t\in\mathsf{sn}$; then, by structural
            induction on derivations of $\mathsf{sn}$
            for $t,u,U$ we get what we want by
            considering all possible reductions.
        \item $n\to(n+1)$. By induction hypothesis, it
            is enough to show the following:
            \[\left\{\begin{array}{l}
                (\lambda(x:U).t)u u_1\ldots u_n
                    \in\mathsf{sn} \\
                t[u/x]u_1\ldots u_{n+1}\in\mathsf{sn}
            \end{array}\right.\Rightarrow
                (\lambda(x:U).t)u u_1\ldots u_n u_{n+1}
                    \in\mathsf{sn}.
            \]
            This is true by structural induction on
            available evidence.
    \end{itemize}
\end{proof}

\subsection{Strong normalization}

\begin{theorem}[Strong normalization of PTS-$rk$]
    \[ \Gamma\vdash t:T\,\land\vdash\Gamma
    \Rightarrow t \in\mathsf{sn}. \]
\end{theorem}
\begin{proof}
    By induction on the typing derivation. Case
    \textsc{Conv} is trivial; due to
    Lemma~\ref{sn-props}, cases \textsc{Ax},
    \textsc{Rule}, \textsc{Var} and \textsc{Abs} present
    no problem as well. The only problematic case is
    application:
    \[
        \left\{\begin{array}{l}
            \Gamma\vdash u:\Pi(x:T).U \\
            \Gamma\vdash t:T \\
            \vdash\Gamma \\
            t,u\in\mathsf{sn}
        \end{array}\right.\Rightarrow u\,t\in\mathsf{sn}
    \]
    Now, here is the part where stratification according
    to ranks comes in useful. As typing yields correct
    type, there is some $r$ such that
    $\Gamma\vdash \Pi(x:T).U:\mathsf{rk}_r$. Let us
    explicitly add this to the list of premises; we will
    call the following proposition
    \emph{Application Lemma}:
    \[ \mathrm{AL}_r \triangleq \quad
        \text{``}\left\{\begin{array}{l}
            \Gamma\vdash \Pi(x:T).U:\mathsf{rk}_r\\
            \Gamma\vdash u:\Pi(x:T).U \\
            \Gamma\vdash t:T \\
            \vdash\Gamma \\
            t,u\in\mathsf{sn}
        \end{array}\right.\Rightarrow u\,t\in\mathsf{sn}
        \text{''}
    \]
    What indexing by $r$ bought us is that now we can
    try proving this lemma by induction on $r$. Again,
    as it always is with strong normalization of
    application, the problem is in case where
    application head is a lambda and a $\beta$-reduction
    takes place. This calls for another lemma,
    \emph{Substitution Lemma}:
    \[ \mathrm{SL}_r \triangleq \quad
        \text{``}\left\{\begin{array}{l}
            \Gamma,x:T,\Delta\vdash u:U\\
            \Gamma\vdash T:\mathsf{rk}_r\\
            \Gamma\vdash t:T\\
            \vdash\Gamma\\
            t,u\in\mathsf{sn}
        \end{array}\right.\Rightarrow
        u[t/x]\in\mathsf{sn}\text{''}
    \]
    A proof of $\mathrm{AL}_r$ for all $r$ (which is
    what we're after) is done by complete mutual
    induction with $\mathrm{SL}_r$. Thus there are two
    main parts:
    \begin{itemize}
        \item $(\forall s<r.\;\mathrm{SL}_s)
            \Rightarrow \mathrm{AL}_r$: by induction on
            derivations of $u,t\in\mathsf{sn}$. Consider
            possible reductions of $u\,t$: most of them
            happen either in $u$ or in $t$, so that
            results of reductions from $u\,t$ are
            strongly normalizing by inductive
            hypotheses. The only problematic case is
            when $u=\lambda(x:T').v$ and the reduction
            is $\beta$-reduction. By inversion of typing
            for $u$, it should be the case that
            $T'=_\beta T$; and by inversion of typing
            for $\Pi(x:T).U$, we get that
            $T:\mathsf{rk}_s$ and $U:\mathsf{rk}_t$ such
            that $r=\max(s+1, t)$. Then, by type
            stability, $T':\mathsf{rk}_s$, and
            furthermore, $s<r$, so we can apply
            substitution lemma.
        \item $(\forall s\le r.\;\mathrm{AL}_s)
            \Rightarrow \mathrm{SL}_r$. So we need to
            prove $u[t/x]\in\mathsf{sn}$. We do it by
            simultaneous induction on derivation of
            $u\in\mathsf{sn}$ and structural induction
            on $u$. As substitution propagates through
            $u$, most cases are satisfied by
            Lemma~\ref{sn-props}. A funny case is when
            $u=x$: then, a premise that
            $t\in\mathsf{sn}$ helps.

            The only problematic case is
            application $u=u_1\,u_2$; we consider three
            cases here:
            \begin{itemize}
                \item $u_1[t/x]$ is atomic --- handled
                    by Lemma~\ref{sn-props}.
                \item $u_1$ is not atomic --- by virtue
                    of it being well-typed, it means
                    that $u=(\lambda(x:V).u')v_1
                    \ldots v_k u_2$. All possible
                    reductions from $u[t/x]$ are then
                    handled by induction hypotheses.
                \item $u_1$ is atomic, but $u_1[t/x]$ is
                    not --- by virtue of $u_1$ being
                    well-typed, the only case when
                    this is possible is when
                    $u_1 = x v_1\ldots v_k$, thus
                    $u[t/x]=t (v_1[t/x])\ldots(v_k[t/x])
                    (u_2[t/x])$. From induction
                    hypotheses we know that all
                    $v_i[t/x]$ and $u_2[t/x]$ are s.n.;
                    $t$ is s.n. by premise and its rank
                    is $r$. Then $t v_1[t/x]$ is s.n. by
                    application lemma for $r$; but note
                    that rank of $t v_1[t/x]$ is not
                    greater than $r$ so application
                    lemma applies again. Thus, by
                    induction on $k$, the whole chain of
                    applications is s.n.
            \end{itemize}
    \end{itemize}
\end{proof}

This is a retelling of a proof that our friend,
Aleksandr Levin, got after half-jokingly inputting the
following prompt into ChatGPT:

\begin{quote}
\begin{verbatim}
Consider the following pure type system:

S = { rk_n | n natural }
Axiom = { (rk_n, rk_0) | n natural }
Rule = { (rk_m, rk_n, rk_max(m+1,n)) | m, n natural }

Is it strongly normalizing or not?
\end{verbatim}
\end{quote}

After approximately 20 minutes, LLM outputted the proof
which we retold above. Looking at it in retrospect, it
seems as if we stratified functions by ranks with intent
for such a direct proof to go through; honestly, we
didn't think of that and were eagerly trying to adapt
well-known approaches for proving normalization of pure
type systems employing either saturated sets or
candidates of reducibility, which didn't work because
our ``hierarchy'' of ranks is not well-founded enough
because of axioms $\mathsf{rk}_n:\mathsf{rk}_0$. This
proof, however, doesn't even bother with it which means
that we could pick \emph{any} relation as
$\mathsf{Ax}$. Nevertheless, putting all sorts into
$\mathsf{rk}_0$ seems the most sensible approach to us
since, informally, sort is kind of a constant which
cannot be converted into a function.
