integration with the parallel GroundHorn and other source changes.

Public interface:

- `compile_predicate`: actual original `Term nat n`, generated by the existing
  `ChurchFinite.map_table` for any finite Boolean table.
- `compile_predicate_typed`, `predicate_program_rank`, `boolean_type_rank`:
  original typing, exact rank r+2 for nonempty query carriers, Boolean rank
  r+1. The zero-arity map is still typed but is not claimed to have rank r+2.
- `compile_predicate_output_exact`: forward original beta reduction to the
  normal Boolean selector iff the table entry equals that Boolean. The reverse
  direction uses original confluence and separation of normal selectors.
- `query_program_true_iff`, `query_program_false_iff`: exact forward beta
  computation iff derivability/nonderivability in the finite ground theory.
- `formula_program`, `completed_formula_program_exact`: generated program
  computes the truth of supported formulas in every signed-completed model.
- `denial_program`, `denial_program_exact`: generated one-query program
  computes true iff a denial-constrained model exists.
- Two closed original-beta regressions: derived query evaluates to true,
  unsupported cyclic query evaluates to false.

All saturation and table generation are external finite computations.
The theorem is not an internal universal reflection theorem, nor a proof of
fixed finite models of the original ungrounded PTS signature. Generated
program size grows with the externally fixed truth-table dimensions; no
bound by the source subject term alone is asserted.
