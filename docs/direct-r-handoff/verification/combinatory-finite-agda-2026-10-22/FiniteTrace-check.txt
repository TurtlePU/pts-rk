Public interface:
  State a n s = Fin (capacity a n s)
  state-bound a d N : a <= N -> AtMost (State a 0 (tower d N))
    (tetration (4*N+4) (d+3))
  state-recovery: decoding an encoded bounded raw term recovers that term.
  compile-bounded: converts each BoundedSteps certificate to FiniteWalk.
  rounds-trace d t: computes the finite-indexed walk for rounds d t.
  walk-sound: decoding a walk gives propositionally truncated forward beta
    reduction, not an arbitrary uninterpreted transition relation.

FiniteWalk constructors contain only finite state indices and proposition-
valued edge certificates. Each state has the displayed finite bound. The
whole type of walks is not asserted finite: walks can have arbitrary length.
The wrapper still constructs the path using Raw internally; it is not a
bound on all host runtime allocations, and does not establish native typed
normality or preservation. The final fresh import-closure audit covers the
complete module dependency closure without cached interfaces.
