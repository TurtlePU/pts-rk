# Independent guard/model review — 2026-10-23

The finite scoped carriers, independently specified Hilbert rule graph and
height-indexed Horn interpretation form a sound construction. Numeric
admission counts annotations, depth and universe labels; it never assumes
native Typ or the intended soundness result. Fixed H uses predicates at
levels 0 through H, and inference advances h to S h. The finite-family
coverage theorem supplies one common envelope for any finite family of
independent Hilbert derivations, not merely their concluding syntax.

R0/R1/R2 are interpreted relations over genuine finite tuple domains and
the clauses quantify over every semantic tuple. This is not the earlier
one-point model with one nullary predicate per original judgment. However,
the first relational construction retains native reduction/conversion as
external meanings of its rule graph. Finite underlying domains do not by
themselves provide a computed table for those predicates. GuardedBetaGraphs
addresses this auxiliary computation by explicitly bounding all path states
and step counts; its integration into selected catalogue/rule tables is a
separate result, not automatic from the relational construction.

Two precise limits should remain visible in the exposition:

- The Hilbert graph model's original h counts inference steps; its N,d guard
  bounds displayed judgments, not intermediate reduction witnesses. The new
  bounded beta graph explicitly adds witness-state and step-count bounds.
- Coverage is for the independent 65-shape Hilbert source. Original-PTS-to-
  catalogue completeness and literal MM0/native graph adequacy remain open;
  neither follows from finite-model soundness.

The Void interpretation is empty even if its code overflows, because all
overflow judgments are false. To avoid a vacuous example, the native Void
code is represented already at N >= 3 and d >= 2; the model also has the
true universe judgment at positive budgets. Its formal Satisfies interface
should restrict the denial's h to h <= H when claiming only H+1 predicate
symbols. The stronger unrestricted denial lemma is harmless separately.
This finite-signature correction was sent to the owning agent.

MM0GuardedQuantification independently counts the complete substituted
instance, including every declared metavariable value and every premise/head
argument. Its inactive clause [head] -> head is exactly tautological and
cannot introduce a new least-model fact. The structural guard representation
law asks for raw decoding of active substituted values, not semantic typing
or the target theorem. Nevertheless concrete representation and candidate
existence must still be supplied; the generic checker/certificate equivalence
does not prove that all guarded literal-MM0 fragments have a model.

No arbitrary-budget internal reflection follows from externally produced
finite certificates. Beta-graph state bounds are also not bounds on host
runtime allocation: constructing a one-step successor can temporarily form
a raw term outside the accepted finite state list before the edge is rejected.
